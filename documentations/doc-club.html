Documentation technique du projet annuel - Option SLAM

1. Présentation du Projet

Le projet Club & Compétitions consiste en la réalisation d'une solution complète (Web et Mobile) dédiée à l'organisation, la gestion et le suivi de tournois sportifs. L'objectif est d'automatiser les tâches administratives complexes telles que la génération de calendriers de matchs et le calcul des classements en temps réel.

2. Analyse et Conception (SLAM)

La phase de conception a été structurée autour de la méthode UML pour garantir une base de données cohérente et évolutive. Le défi technique majeur résidait dans la gestion des relations entre les clubs, les différentes éditions des compétitions et les résultats des matchs.

3. Architecture Technique (Stack)

Pour assurer une synchronisation fluide entre la gestion web et la consultation mobile, j'ai opté pour une architecture basée sur une API REST centrale.

Couche Technologie Rôle
Backend / API Node.js / Express (ou PHP) Logique métier et service des données JSON.
Frontend Web React.js (ou HTML/CSS) Interface de gestion pour les organisateurs.
Application Mobile Flutter / React Native Consultation des scores et notifications.
Base de données MySQL / PostgreSQL Stockage persistant des données structurées.

4. Implémentation : Logique de Classement

Conformément aux exigences de l'option SLAM, le code suit une structure détaillée et commentée pour assurer une maintenance optimale par d'autres développeurs.

Extrait : Calcul automatique des points d'un match


/**
 * Calcule et met à jour les points suite à la saisie d'un score.
 * Les codes sont détaillés pour une lisibilité maximale.
 */
function processMatchResult(matchId, scoreA, scoreB) {
    const WIN_POINTS = 3;
    const DRAW_POINTS = 1;
    const LOSS_POINTS = 0;

    const currentMatch = database.getMatch(matchId);
    
    // Comparaison des scores pour déterminer l'issue
    if (scoreA > scoreB) {
        // Victoire de l'équipe domicile
        updateTeamPoints(currentMatch.teamA_id, WIN_POINTS);
        updateTeamPoints(currentMatch.teamB_id, LOSS_POINTS);
    } 
    else if (scoreA < scoreB) {
        // Victoire de l'équipe visiteur
        updateTeamPoints(currentMatch.teamA_id, LOSS_POINTS);
        updateTeamPoints(currentMatch.teamB_id, WIN_POINTS);
    } 
    else {
        // Match nul
        updateTeamPoints(currentMatch.teamA_id, DRAW_POINTS);
        updateTeamPoints(currentMatch.teamB_id, DRAW_POINTS);
    }
}
